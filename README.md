# COMP4610 Group 18：CARLA恶劣天气目标检测与驾驶基线

这是第18组第二周阶段成果仓库，记录了从开源YOLO11n检测器建立CARLA驾驶基线、制作晴雨配对数据、完成两次50轮微调，到统一评价与失败分析的全过程。

## 本周完成内容

- 在CARLA中接入YOLO11n检测器，完成行人横穿时的停车、等待、恢复和到达终点流程。
- 设计5种行人横穿设置，并在晴天与强雨天各运行一次，共10次闭环驾驶基线。
- 在Town02生成600对晴雨图片，共1,200张RGB图像，并由CARLA实例分割真值生成车辆与行人检测框。
- 从同一个预训练权重出发，分别微调晴天模型和雨天模型，各50轮。
- 使用原始模型、晴天微调模型和雨天微调模型，在晴天与雨天测试集上完成6组统一评价。
- 回看S04雨天碰撞日志，定位到检测稳定性、横向位置边界与规则控制衔接问题。

## 系统流程

```text
CARLA RGB相机
      ↓
YOLO11n车辆/行人检测
      ↓
几何位置与危险区域判断
      ↓
规则控制油门和刹车 + 地图路点转向
      ↓
逐帧日志、关键帧、视频与碰撞记录
```

当前YOLO负责感知，油门和刹车由规则控制，转向使用地图路点。项目尚未训练驾驶控制网络。

## 主要结果

### 闭环驾驶基线

| 天气 | 无碰撞到达 | 曾达到停车阈值 |
|---|---:|---:|
| ClearNoon | 5/5 | 4/5 |
| HardRainNoon | 4/5 | 4/5 |

停车阈值定义为车速低于0.2 m/s。五组配对中，雨天首次刹车平均比晴天晚0.33秒。样本量较小，这些数字只描述本轮先导测试。

### 离线检测评价

| 模型与测试集 | mAP50–95 |
|---|---:|
| 原始模型，晴天测试 | 26.3% |
| 晴天微调模型，晴天测试 | 41.0% |
| 原始模型，雨天测试 | 15.9% |
| 雨天微调模型，雨天测试 | 39.4% |

匹配天气下，晴天微调增加14.6个百分点，雨天微调增加23.5个百分点。该结果证明本次仿真测试图上的检测指标提高，尚不能证明闭环驾驶安全已经提高。

## 环境

- Windows
- CARLA 0.9.15
- Python 3.10
- PyTorch 2.5.1
- Ultralytics 8.3.40
- RTX 4060 Laptop GPU，8GB显存

安装Python依赖：

```bash
pip install -r requirements.txt
```

CARLA服务端需要单独安装并启动。本仓库不包含CARLA安装包。

## 当前限制与下一步

- 数据来自Town02和两种天气，不能代表真实道路或所有场景。
- 当前只有一个训练随机种子，没有统计显著性检验。
- 10次驾驶使用原始检测模型，新模型尚未重新进入闭环驾驶。
- 下一步固定控制器，执行3个模型 × 5种横穿设置 × 2种天气，共30次闭环测试。
- 后续使用相同训练预算比较有无天气增强，单独研究增强对鲁棒性的作用。
- 是否训练控制模型需要进一步确认；如需要，应另行采集可靠专家驾驶示范。
